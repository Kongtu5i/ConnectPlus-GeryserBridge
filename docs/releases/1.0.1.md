# ConnectPlus-GeyserBridge 1.0.1

独立 Geyser 扩展，为同一 ViaProxy 进程中的 ConnectPlus 提供经过验证的基岩 XUID、精确连接绑定和定向断开。

本版本建议作为预发布版：自动测试已通过，真人客户端验收尚未完成。

## 安装

下载 `connectplus-geyserbridge-1.0.1.jar`，放入 ViaProxy 工作目录的 `plugins/Geyser/extensions/`，然后重启 ViaProxy。通过发布附件 `SHA256SUMS` 核对文件。

需要支持桥接协议 v1 的 ConnectPlus；当前集成基线为 ConnectPlus 0.1.0。官方 ViaProxy 和 Geyser-ViaProxy 需另行安装。

## 兼容范围

- Java 21 或更高版本。
- Geyser 2.11.x，最低 2.11.3；ViaProxy 3.4.x，最低 3.4.13。启动时还需通过只读适配器探测和认证配置检查。
- 已记录的自动启动基线：官方 Geyser 2.11.3 build 1247、官方 ViaProxy 3.4.13、Java 21。
- ConnectPlus：`mode: lobby`、`geyser-support.enabled: true`、`allowAccountLogin: true`。
- Geyser：开启 `advanced.bedrock.validate-bedrock-login`、关闭 `use-waterdogpe-forwarding`，认证类型不得为 FLOODGATE。

版本范围内的新版本仍需验证；无法通过探测时停用桥接。

## 行为

注册能力为 `verified-xuid`、`exact-channel-binding` 和 `targeted-disconnect`。使用未修改的官方宿主，不提供重复 XUID 登录准入：同一 Xbox XUID 重复登录时，原客户端保持在线，新连接由 Geyser 原生拒绝。关联 Java 档案后的 Java/基岩会话互斥由 ConnectPlus 管理。
